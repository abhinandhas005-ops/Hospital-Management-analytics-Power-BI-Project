Hospital Management Analytics Dashboard - Power BI Project

📌 Project Overview
-------------------
This project is a Power BI data analysis project that analyses hospital operations using appointment, treatment, billing, doctor and patient data.

It covers importing data from Excel, building a data model, writing DAX measures, and creating an interactive 3-page dashboard.

🛠️ Tools & Technologies
----------------------
- Power BI Desktop
- DAX
- Microsoft Excel
- Git & GitHub

📂 Project Files
------------------
- my_project.pbix – Power BI report with the data model, DAX measures and dashboards.
- Hospital_management_dataset.xlsx – Dataset (doctors, patients, appointments, treatments and billing).
- HOSPITAL_ANALYSIS_DASHBOARD_3pages_model_view.docx – Dashboard and model view screenshots.

🔍 Power BI Concepts Used
--------------------------
- Data import and transformation (Power Query)
- Data modeling and relationships
- DAX measures and calculated columns
- Slicers and filters
- Bookmarks and page navigation buttons
- KPI cards, combo charts, donut charts and matrix visuals

🎯 Project Objectives
------------------------
- Practice data modeling and DAX using healthcare data
- Track appointments, revenue and payment status
- Compare doctors, branches and specializations
- Analyze patient registrations, age groups and insurance providers
- Build a portfolio project for GitHub

📊 Analysis
--------------
The dashboard answers questions such as:

- How many appointments were completed, cancelled, scheduled or no-show?
- What is the total revenue, and how much is collected, pending or failed?
- Which branches, doctors and treatments perform best?
- How do patient registrations change over time?

Report Pages
------------
- Overview – Revenue KPIs, monthly appointments and revenue trend, branch and treatment analysis, payment status
- Appointments & Doctors – Appointment status, no-show rate, doctor performance, weekday and hour heatmap
- Finance & Patients – Patient registrations, pending and failed amounts, age group and gender, insurance providers

Key Insights
------------
- Total revenue of ₹551.25K: ₹173.42K collected, ₹184.61K pending and ₹193.21K failed
- 200 appointments across 3 branches, with a 26% no-show rate
- Chemotherapy is the top treatment by revenue
- Pediatrics handles the most appointments

🚀 How to Run the Project
---------------------------
1. Install Power BI Desktop.
2. Clone this repository:
  ```
   git clone https://github.com/abhinandhas005-ops/Hospital-Management-Analytics-PowerBI-Project.git
   ```
4. If prompted, update the data source: Home → Transform data → Data source settings, and select Hospital_management_dataset.xlsx.
5. Click Refresh and explore the report using the slicers and page buttons.
